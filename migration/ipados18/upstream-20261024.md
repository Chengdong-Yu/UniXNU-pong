## 已阅读与理解

- [设备迁移](https://unixnu.com/zh/porting/migration)、[设备仓库](https://unixnu.com/zh/porting/device-repository)、[组件目录](https://unixnu.com/zh/reference/components)：格式2按 ARM64、SoC、OS、设备解析；普通数组替换继承数组。组件仓库改用规范名称，运行时类名、符号、bundle 与协议 ID 保留。Pong 的 A730 分支继续保留自己的身份和硬件适配。
- [设备树](https://unixnu.com/zh/porting/device-tree)：arm-io 父物理基址必须非零，标准子节点 reg 为窗口偏移。当前 Pong ADT 已使用非零 APSS_BASE 与 GIC 相对偏移；Goodix、UFS 等驱动按自定义属性读取的绝对地址仍遵循各自接口，不参与该标准 reg 换算。
- [GPU](https://unixnu.com/zh/porting/gpu)、[Adreno740](https://unixnu.com/zh/drivers/adreno740)、[AdrenoMetal](https://unixnu.com/zh/drivers/adreno-metal)：设备发现、原生客户端、真实 CP/fence、Metal 编译和 scanout 是独立检查点。上游当前适配范围为 A740/SM8550/21H461。Pong 保留 A730 固件与板级资源，22H374 的 600 字节 `_MTLDevice` 和 IOGPUFamily 绑定也保留。
- [日志抓取](https://unixnu.com/zh/porting/log-capture)、[适配记录](https://unixnu.com/zh/porting/records)：固件日志、内核日志和设备运行结果分别记录；编译成功不能升级为实机可用状态。

## 合并结果

1. 合入上游 `578cf86` 的有效启动参数打印，在 DarwinBoot24 退出 Boot Services 前输出实际 command line；原有绿色条只表示 loader 交接的准确说明已存在。
2. 同步 Adreno740 的规范来源引用，保留 Pong user client、符号和协议标识。相对已记录的 b686b90/c6d29ca 基线，Adreno740、AdrenoMetal 本轮差异只有来源名称、说明和 AGENTS，运行代码没有新增的 CP/Metal 修复；没有把同一代码重复覆盖到 Pong。
3. 按上游 OS ABI 分层要求，插件构建器现在要求 bridge 的 guest 和 `_MTLDevice` 大小与所选 guest 匹配，阻止 22H374 插件误链接缓存的 20G81 bridge。此检查读取构建元数据，不计算镜像散列或读回镜像。
4. Sheng 本轮新增 32 位/4 GiB GPU aperture。Pong 现有实现已经使用 32 位 GPU VA、2053 页表页和不重叠的客户端窗口；上游旧 display probe 编译条件也已经在当前 Darwin24 补丁中存在。
5. 保留 services36 的 64 KiB 缓存维护批次；上游组件没有替代这项 Darwin24 抢占超时修复。

## 需要独立适配的内容

- 格式2的完整构建配置迁移，需要真实 SM8475 SoC 配置和 22H374 OS profile；当前上游的 SM8550/21H461 不能作为这两项输入。现有 Darwin24 构建入口继续使用准确源码与 ABI。
- Sheng 的新 Wi-Fi、ADSP、音频、电池和调频代码依赖其设备固件、供电、寄存器和 OS 接口，尚未构成 Pong 对应硬件的实现。
- 最新文档描述空闲时全系统 metallib 预编译。固定版本 `AdrenoMetal/PrimeShaders.h` 使用 90 秒延迟和每函数 20 ms 间隔，未找到文档所述每 250 ms/超过8次提交的空闲负载门限。Pong 后续接入需先取得真实 GPU/Metal 执行结果，再使用本机 22H374 库清单和 cryptex 可访问路径；不能以 Sheng 的库清单或完成数量作为 Pong 结果。

## 构建与设备状态

DarwinBoot24 已与最新通用 package 编译链接完成；新增版本匹配条件后的 22H374 Metal 插件也已编译链接完成，继续使用现有同版本 bridge 和 Pong Turnip。日志位于本机外置 `upstream-sync-20261024/`。本轮没有运行测试、性能测量、镜像散列或设备镜像读回。

本轮没有组装新的启动镜像或操作手机，手机最后临时启动的仍为 services36。新 loader 和插件产物供后续启动镜像采用；尚无新硬件运行结论。
