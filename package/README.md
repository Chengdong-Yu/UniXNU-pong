# Pong package inputs

Generated package contents are written under the ignored `out/` directory. This source repository does not contain a built kernel package, IPSW component, trust cache, ramdisk or userdata image. The format 2 configuration selects the Pong SM8475 board and locally fetched iPadOS 18.7.10 / 22H374 inputs. Use the Darwin24 build and prelink entry points documented in the root README; the generic Darwin23 package entry does not replace them.
